# 简答题

1. 在我们的easy-fs中，root inode起着什么作用？如果root inode中的内容损坏了，会发生什么？

    root inode是文件系统的根目录，是文件系统的入口，在项目中通过 ROOT_INODE 这个全局静态变量访问文件系统。此外，root inode 存储了所有文件的目录项，文件名需要借助 root inode 转换为对应的 inode id。

    如果 root inode 损坏，将无法访问文件系统。

2. 举出使用 pipe 的一个实际应用的例子。

    常用的一个使用fzf的方式，在当前文件夹查找文件，并通过nvim打开：

    ```bash
    fzf --preview 'head -n 50 {}' | xargs nvim
    ```

    如何使用 cat 和 wc 完成一个文件的行数统计?

 
    ```bash
    cat FILE | wc -l
    ```

3. 如果需要在多个进程间互相通信，则需要为每一对进程建立一个管道，非常繁琐，请设计一个更易用的多进程通信机制。

    可以参考 Linux 的共享内存机制，将一块物理内存映射到多个进程的虚拟地址空间中，通过读写这一块区域，实现数据共享。
